DOS/V エミュレータ — 本物の ＪＷ＿ＣＡＤ が動きます

ここで動いているのは移植ではなく、1999 年の実行ファイルそのものです。 JW_CADV.EXE を 16 ビットの x86 として 1 命令ずつ実行し、DOS と BIOS と VGA とマウスドライバを下から支えています。画面はプログラム自身がプレーンに 書いた画素で、フォントも DOS/V と同じように OS（＝このエミュレータ）が渡しています。

読み込み中… 


  

    

      左ボタン＝指示、右ボタン＝読取。メニューは画面の左、レイヤは右下。
      キーボードもそのまま届きます（一文字キー、数字、[Enter]、[BS]、[ESC]、[F1]〜[F10]）。
      文字コマンドでは日本語も打てます——OS の入力メソッドで変換して確定すると、
      本物がそれを受け取ります。起動に 4000 万命令ほどかかるので、最初の画面までは数秒かかります。
    

    

      図面を開く・保存するのは JW_CAD の 入出力 です。
      上の 3 つは、手元のパソコンとエミュレータの中のディスクとの間で
      ファイルを出し入れするだけで、開いたり閉じたりはしません。
    

    

      ＰＤＦ と ＰＮＧ は「プロッタ出力」です。
      JW_CAD の中でこう進みます:
    

    
    
      
  1. 画面左のメニューのいちばん下 入出力 を押す
    2. 
      
  2. 上の行の ②プロッタ を押す
    3. 
      
  3. 上の行の ③ﾌｧｲﾙ出力 を押す
          （プリンタポートではなくこちらです）
    4. 
      
  4. 出てくる一覧から WASM.JWP を選び、
          上の行の ①選択確定 を押す
    5. 
      
  5. 出力ファイル名 ? と聞かれるので
          PLOT のように打って [Enter]
    6. 
      
  6. 上の行の ①確定 → ① 実行
    7. 
      
  7. 「作図処理中」の数が 0 になるまで待つ（図面によっては数十秒）
    8. 
      
  8. 一覧に PLOT が出たら、ここの
          ＰＤＦ か ＰＮＧ を押す
    9. 
    

    

      ＰＤＦ／ＰＮＧ の釦は、プロッタ出力のファイルがまだ無いあいだは
      押せません。WASM.JWP は、本物のプロッタの言葉（HP-GL）の
      代わりに読みやすい行を書かせるための設定ファイルで、こちらで用意して
      あります。
    

    

      アップロード——手元の .JWC をディスクに置きます。開くのは
      そのあと 入出力 → ①ファイル → ②読込 で。
      （作図中のものは消えません。）

      ダウンロード——一覧で選んだ図面を手元に保存します。取り出せるのは
      ディスクにある中身なので、作図したものが欲しいときは先に
      入出力 → ①保存 してから押してください。
      保存して増えた図面には ● が付き、そのまま選ばれた状態になります。

      jwcad_dos_wasm。
